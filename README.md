# 🦉 EngFun ป.1 — เว็บเรียนภาษาอังกฤษ ชั้นประถมศึกษาปีที่ 1

สื่อการเรียนรู้ภาษาอังกฤษเชิงโต้ตอบสำหรับนักเรียนชั้นประถมศึกษาปีที่ 1 (ป.1) ใช้งานได้ทันทีผ่านเว็บเบราว์เซอร์

## ฟีเจอร์หลัก
- 📚 **6 บทเรียนครบหลักสูตร ป.1**: Greetings, Numbers 1–10, Colors, Animals, My Classroom, My Body
- 🔊 **เสียงอ่านภาษาอังกฤษอัตโนมัติ** พร้อมโหมดอ่านช้า (🐢) และเปิด/ปิดคำอ่านภาษาไทย
- 🔤 **ห้องเรียน ABC & กระดานฝึกเขียนวิเศษ** (A–Z พิมพ์ใหญ่/พิมพ์เล็ก)
- 🎮 **3 เกมทบทวน**: ฟังเสียงแล้วทายภาพ, จับคู่ความจำ และควิซ 5 ข้อ
- 📽️ **โหมดสอนทีละคำ & โหมดจอใหญ่** สำหรับครูผู้สอนในห้องเรียน
- 🏆 **ระบบสะสมดาวและสมุดสติกเกอร์**
